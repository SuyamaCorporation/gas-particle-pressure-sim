## 気体分子・圧力シミュレーション

ボックス内の気体分子（粒子）が弾性衝突する理想気体モデルをCanvas上でシミュレーション。

### 機能
- Canvas 2D による粒子弾性衝突シミュレーション（20〜200個）
- 温度スライダー: 粒子速度スケールをリアルタイム変更
- 体積スライダー: ボックス幅を変更してボイルの法則を体験
- 粒子数スライダー: 粒子の追加・削除
- P・V・T 数値表示（P=衝突頻度×平均運動量/壁面長）
- PV/NkT 理想気体定数のリアルタイム検証
- 速度分布ヒストグラム（SVG棒グラフ + マクスウェル-ボルツマン理論曲線）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API / requestAnimationFrame
- SVG 動的生成（速度分布ヒストグラム）
- 粒子間衝突: O(N²) 近傍検索 + 弾性衝突解析
